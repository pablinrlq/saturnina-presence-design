# Saturnina Presence Design

Quero que você desenvolva o design e a interface completa de um site premium para a marca SATURNINA.

IMPORTANTE:

Eu fornecerei:

1. O PDF oficial de identidade visual da Saturnina.

2. Uma imagem de referência da tela de login do Saturn Club.

Esses materiais são a fonte principal de verdade para o design.

Não crie uma identidade visual diferente.

Não transforme o projeto em um template genérico de salão de beleza.

==================================================

1. SOBRE A MARCA

==================================================

SATURNINA é uma marca de beleza e experiência feminina.

Posicionamento:

"Uma marca de beleza e experiência feminina que utiliza a estética como portal para revelar presença, identidade e sofisticação de forma autêntica e sensorial."

Propósito:

"Revelar a presença feminina através da beleza."

Assinatura principal:

"Beleza que revela presença."

A personalidade visual precisa transmitir:

- sofisticada

- desejada

- conceitual

- premium

- memorável

- elegante

- sensorial

- acolhedora

- editorial

- feminina

- silenciosamente luxuosa

A marca NÃO deve parecer:

- extravagante

- genérica

- artificial

- exagerada

- carregada

- cheia de informação

- um template pronto de salão

- um sistema SaaS genérico

A sensação desejada é de uma marca de beleza autoral/editorial que poderia existir em São Paulo, Paris, Milão ou outra grande capital da moda.

Luxo silencioso, não ostentação.

3. TIPOGRAFIA

==================================================

A identidade utiliza:

Editorial New

→ títulos

→ frases de impacto

→ números grandes

→ elementos editoriais

Helvetica Neue

→ textos

→ formulários

→ menus

→ legendas

→ informações funcionais

Caso Editorial New não esteja disponível, utilizar uma alternativa premium editorial extremamente semelhante.

NÃO utilizar fontes genéricas que destruam o conceito da marca.

A tipografia deve ser parte importante da composição.

Títulos podem ser enormes.

Algumas palavras podem ultrapassar visualmente grids tradicionais, como acontece em editoriais de moda.

6. HOME

Sua força.

Sua presença."

==================================================

23. DIREÇÃO FINAL

==================================================

A pergunta para cada tela deve ser:

"Isso parece Saturnina ou poderia pertencer a qualquer salão?"

Se puder pertencer a qualquer salão, refaça.

A experiência deve transmitir:

SATURNINA

CONCEPT HAIR

Beleza que revela presença.

Quero que o usuário perceba a marca como premium antes mesmo de ler qualquer texto.

Utilize o PDF e a imagem de login fornecidos constantemente como referência durante o desenvolvimento.

Não invente outra identidade.

Não simplifique a marca para um template.

Não descaracterize a tipografia.

Não adicione elementos apenas para preencher espaço.

O espaço vazio faz parte do design.

Comece criando primeiro:

1. Design System

2. Tela de Login Admin

3. Homepage

4. Fluxo de Agendamento

5. Dashboard Admin

Depois utilize esses elementos como linguagem visual para desenvolver o restante do sistema.

O resultado precisa parecer um projeto feito por uma agência de branding + estúdio digital premium, e não um template comprado e personalizado.
